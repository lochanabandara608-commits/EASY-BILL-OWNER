  1. Firebase console → Authentication → make sure account superadmin@easybill-lk.firebaseapp.com exists (create it first, so nobody else can take that username).
  2. Firebase console → Firestore Database → Rules → replace everything with the rules below → Publish.
  3. Open the POS on each shop device once (updated version). They appear here within 2 minutes.
